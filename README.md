# DSA Lab

**Every data structure, animated step by step **

DSA Lab is built with an intent to help students. It follows the order of a standard data-structures
course (the chapters of *Schaum's Outline of Data Structures*) and lets students run each
algorithm one step at a time, on their own input.


---

## What's inside


| Topic | Simulations |
|---|---|
| Arrays & Matrices | Traversal · Insertion · Deletion · 2-D arrays in memory · Matrix multiplication · Sparse & triangular matrices |
| Linked Lists | Singly linked list · Memory view (INFO / LINK / AVAIL) · Circular list · Header lists · Two-way list · Polynomial addition |
| Stacks | Stack using an array · Stack using a linked list · Balanced parentheses |
| Polish Notation | Infix → postfix · Infix → prefix · Evaluating postfix · Evaluating prefix |
| Queues & Deques | Linear queue · Circular queue · Linked queue · Deque · Priority queue |
| Recursion | Call stack (factorial, Fibonacci, GCD, power, Ackermann) · Towers of Hanoi |
| Strings & Pattern Matching | String operations · Brute-force matching · KMP (failure table) |
| Searching | Linear search with a sentinel · Binary search · Interpolation search |
| Sorting | Bubble · Selection · Insertion · Shell · Merging · Merge sort · Quicksort · Heapsort · Radix · Counting |
| Hashing | Hash functions · Open addressing (linear, quadratic, double hashing) · Chaining |
| Binary Trees | Traversals · Representation in memory · Expression trees · Threaded trees · General trees |
| Search Trees | BST · AVL · m-way search tree · B-tree |
| Heaps & Huffman | Heap insertion & deletion · Huffman's algorithm |
| Graphs | Representations · Warshall · Floyd · BFS · DFS · Topological sort · Dijkstra · Prim · Kruskal |
| Complexity | Growth of functions (Big-O race) |

Every simulation page has:

- **Player controls**: play, pause, step forward, step back, a scrubber and a speed control.
  Keyboard: `Space` play/pause, `←` / `→` step, `Home` / `End` jump to the start/end.
- **Your own input**: type values, press an operation (PUSH, INSERT, DELETE …), use the dice
  for random data, and Undo or Reset at any time.
- **Pseudocode** written in the textbook's style, with the current line highlighted.
- **Variables** (changed values light up) and a **trace table** of every step.
- **Explanation** of each step in plain words, and a **theory** tab with complexity.
- The same algorithm in **C and Python**, with a **Run in Code Lab** button.

### Code Lab (`#/lab`)

A small VS Code in the browser
Works on phones, tablets and computers.
